Inputs

Every input goes to one folder, the store, which all services share, so a layer that two services use is downloaded once. esa inputs lists the inputs with their state, and esa fetch downloads what is missing. The fetchers write each file under a temporary name and rename it when it is complete, so an interrupted download leaves nothing half written. The code annex of each service page describes what its fetchers do, and the catalogue and the fetchers hold the code.

Releases

Corine, the NUTS boundaries, the productivity, the bumblebee model and the crop data are fixed releases, so a new download gives the same files. Eurostat revises its datasets with each release, and so the fetcher records the date of retrieval of every extract in the file extracts.json beside it. The report of each run lists its inputs with those dates. Eurostat publishes the EU27 price index from 2000, and the fetcher estimates the years before from the rates of the euro area and the other Member States, as the page on crop pollination explains.

Keys

The annual productivity needs a free account of the Copernicus Data Space Ecosystem with S3 keys, in the variables CDSE_S3_ACCESS_KEY and CDSE_S3_SECRET_KEY. The tool never writes the keys to a file or a log. Reading the 180 files of the productivity takes several hours, and all other inputs take a few minutes.
